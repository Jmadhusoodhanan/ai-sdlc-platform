# AI SDLC Platform

An AI-assisted software development lifecycle platform
for orchestrating requirements, planning, implementation,
testing, code review, and human approvals.

## Architecture

- Frontend: React and TypeScript
- Orchestration API: ASP.NET Core
- Persistence: PostgreSQL
- Execution: Isolated task workers
- Integrations: GitHub, AI model providers, and MCP tools

## Status

Phase 1: Repository and workflow engine foundation.
